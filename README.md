
# Project Title

Emotion Based Music Recommendation System

## About

This Project is about taking input as facial expression and Text. Based on prediction it will provide the music recommendation.

### Prerequisites

Install Django.
Install Tensorflow.
Install Huggingface Library

Maintain an env for Django file.

## Running the tests

Uing python manage.py test we can perform Unit testing.

## Versioning

python 3.10
django 5.1.1
